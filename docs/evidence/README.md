# Evidence scope

The `linux_*.json` and `linux_*.csv` files are historical measurements from a prior Linux source snapshot. Subsequent boundary fixes mean they must not be described as validation of the current source without rerunning on Linux and recording its source identity. The `windows-localhost-20261113` directory contains the newer Windows localhost run and states its timing and packet-loss limits. Local full experiment artifacts remain in ignored `benchmarks/audit-*` directories.
