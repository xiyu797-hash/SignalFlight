# Windows 本机 UDP 实验，2026-11-13

实验使用当前 V1.8 源码的独立 VS2026/MSVC 19.51 Release 构建；CTest 2/2、项目常规验证 8/8。Windows 11 26100 x64、Intel i9-12900H。数据是 localhost UDP 回环，并非物理网络、长期稳定性或饱和吞吐实验。

六轮各使用 4 个发送进程、每进程 2 条逻辑流，每流 400 帧、每帧 1024 个 IQ 样本、每包 128 个样本；接收端 2 个 worker、队列上限 512。每进程每流 40/80/120 帧每秒各测两次，名义总速率 320/640/960 帧每秒；实际发送节奏可能受生成与调度限制。完整发送及接收各 25,600 包、处理 3,200 帧，六轮均无发送错误、最终缺失、过期或队列丢弃。

[`summary.csv`](summary.csv) 原样保留每轮汇总。`p99_us` 为接收端已处理帧从接收端处理该帧首个分片到分析完成的 P99，不是网络或端到端延迟，也不包括未处理帧。`receiver_cpu_one_core_pct` 为接收进程 CPU 时间除以发送阶段时长、以一个逻辑核为 100%，不包含发送端。`wall_s` 包含发送端节流及收尾时间，不能用它直接声称接收端吞吐极限。每档仅两次，不能判断趋势。

完整本机原始日志和试验时源码哈希保留在本地 `benchmarks/audit-20261113-load`；该目录是生成产物，默认不纳入仓库。Linux 当前源码、独立主机网络、发送端 CPU 与优化前后同条件对照仍未完成。
